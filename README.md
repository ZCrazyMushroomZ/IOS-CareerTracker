# Job & LeetCode Tracker iOS App

An iOS application designed to manage job applications and track LeetCode progress.

## Features

- 📱 Job Application Management
- 📊 LeetCode Progress Tracking
- 🔐 Secure User Authentication
- 🔄 Real-time Data Updates

## Tech Stack

- **Frontend**: Swift
- **Backend**: Firebase
- **API**: GraphQL
- **Authentication**: Firebase Authentication
- **Database**: Firebase Realtime Database

## Key Features

### Job Tracking
- Manage job application statuses
- Track interview progress
- Save important dates and reminders

### LeetCode Progress
- Real-time LeetCode progress tracking via GraphQL
- Problem completion status by difficulty level
- Track solving dates and completion times

### User Authentication
- Secure authentication powered by Firebase
- Google account integration
- Real-time data synchronization and backup

## Requirements

- iOS 14.0 or later
- Xcode 13.0 or later
- CocoaPods
